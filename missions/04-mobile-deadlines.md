# Mission Card 04 — Mobile polish + deadline urgency

## 🎯 Goal
- Deadlines show urgency with **words AND colour**:
  **Overdue** (red) for past dates, **Due soon** (orange) within 7 days,
  otherwise the plain date.
- A final mobile + accessibility pass: big tap targets, clear labels,
  one column on phones, keyboard works.

## 🚧 Limits
- No new features (no editing/deleting, no server).
- Sample data only.

## 🧪 Your self-test
1. Add a task with yesterday's date (change the date picker or add via
   the form) → badge line shows **Overdue** in red words.
2. Add a task 3 days ahead → shows **Due soon** in orange.
3. Add a task 30 days ahead → plain date, no warning colour. ✅
4. Shrink the browser window to phone width → everything stays in one
   column, buttons still comfortably tappable.
