# Mission Card 02 — Pick up and complete tasks

## 🎯 Goal
Each task gets a **status**: To do → In progress → Done.
Buttons to "Pick up" a task (assigns to you, the demo user) and
"Mark done". Status shows as a badge with words AND colour.
Also fixes the Mission 01 red-team note: error and empty state
must never show at the same time.

## 🚧 Limits
- No real login — "picked up by" is a demo name (`You`).
- No deadline urgency colours yet (Mission 04).
- No editing/deleting tasks in this card.

## 🧪 Your self-test
1. Add a task → badge says **To do** (grey).
2. Click **Pick up** → badge changes to **In progress** (orange), button becomes **Mark done**.
3. Click **Mark done** → badge **Done** (green), title gets a strike-through.
4. **Refresh** → all statuses are still correct. ✅
