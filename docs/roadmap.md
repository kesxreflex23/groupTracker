# Roadmap — Mission Cards

One Mission Card at a time. Each ends with a self-test you run yourself.
After each card: open the preview, try it, and `docs/savefile.md` gets updated.

## Mission 01 — Task list that survives a refresh (IN PROGRESS)
Build the page: a task list with title + deadline, an "Add task" form,
saved in localStorage so it survives refresh. Handles empty and error states.

## Mission 02 — Pick up and complete tasks
Buttons to pick up a task (assign to "me") and mark it done,
with status badges (To do / In progress / Done).

## Mission 03 — Roles demo (Student / Tutor)
A role switcher in the header. Tutor view adds a demo badge/notice.
Explains why this is a demo, not real login/security.

## Mission 04 — Mobile polish + deadline urgency
Responsive check on phone size, colour/label for approaching deadlines,
final accessibility pass.

## Mission 05 — Documentation wrap-up
README, ARCHITECTURE.md, test results log, and how to push to GitHub
so Apexelerate can find the project.

## Out of scope for version one (by design)
Real logins, a shared server/database, payments, email reminders.
